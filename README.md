- 校验指定时间范围，程序会自动按月份拆分抓取：
  - `python verify_csv_integrity.py --start-date 2022-01-01 --end-date 2022-12-31`

  - `python verify_csv_integrity.py --start-date 2022-01-01 --end-date 2022-12-31 --repair`
